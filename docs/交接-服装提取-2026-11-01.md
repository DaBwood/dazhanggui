## 4. 关键技术坑（dsh 必读）

### 4.1 预乘 alpha（pma）

皮肤图集是**直通 alpha**。之前渲染用 `premultipliedAlpha=true`，半透明区域会被当成亮色，出现大片白块。

- 渲染页已加参数：`pma=0`
- 工具：`--pma 0`
- **场景类皮肤必须 pma=0**，否则会有矩形亮块。

### 4.2 叠加混合特效层（白块 / 白雾 / 鬼影）

Spine 里 `blendMode != 0`（additive/screen/multiply）的特效层，在透明底上会变成白块、白雾、白鬼影。

- 渲染页加 `noblend=1`：跳过所有非 normal 混合的槽位
- 工具：`--noblend`
- 典型：火焰、光效、烟、风、雪花、月相卡片

### 4.3 NPOT + `repeat: xy` → 整张黑 / 白

`109669`（相濡以沫）的 atlas 是 **1571×1571 非 2 的幂 + `repeat: xy`**。
WebGL1 下这种纹理不完整，整张骨架采样成黑色（黑方块 + 黑剪影）。

- 已在 `render_skin_spine.py` 的 `prepare_stage` 里强制把 `repeat: xy` 改成 `repeat: none`
- 判断方法：atlas 页尺寸非 2 的幂，且带 `repeat: xy`
- 全量扫描过 221 个挚友 skin，只有 109669 命中

### 4.4 图集缺 region（109758）

`109758` 的 `.skel` 引用了 atlas 里不存在的 `3qi_22`，直接渲染失败。
`tools\patch_109758_atlas.py` 会给 atlas 追加一个 16×16 透明占位页 `patch.png`。
游戏原作 109255 里这个 region 也只是透明占位。

### 4.5 Edge 缓存

Edge 会缓存 `skeleton.atlas` / `skeleton.json` / 渲染 HTML，改完资源后仍用旧文件。
两个渲染页已加：

- `fetch(..., { cache: 'no-store' })`
- `?v=Date.now()` 时间戳

还不行就删掉 `C:\Users\林\AppData\Local\Temp\opencode\skin_render\edgeprofile*`。

### 4.6 `--hide` 的匹配规则陷阱

当前规则：
- **纯数字**（`^\d+$`）→ 精确匹配
- 其他 → **子串匹配**

所以 `--hide "1_4"` 会把 `1_40`～`1_49` 全部隐藏。门客/皮肤的槽位如果是 `1_0`、`1_1` 这种，务必写全名，或改成精确匹配。

### 4.7 出场动画帧

- 默认渲染的是 **setup pose**，绝大多数是正确的“站定”画面。
- 批量切 `--anim idle --time end` 在部分皮肤上会变得更糊/更亮（特效在末帧最强），**不要全量切**。
- 用户反馈的“刚出场画面”多数其实是**叠加层盖住人物**，用 `--noblend` 已解决。
- 只有少数皮肤确实 setup 不对，再单独取 `--time end`。

### 4.8 白块/装饰槽的识别方法

这类槽位名字通常有规律：

- 纯数字：`01`～`012`（月相卡片、纸片）
- 前缀：`ef_`、`wu`、`yan`、`sha`、`smoke`、`glow`、`lzlg`、`xuehua`、`huaban`
- 大背景：`0110`～`0161`

定位手段：
1. 用 `tools\_spine_render_multi*.html` 的 `dump=1` 输出槽位名/混合模式/颜色/UV
2. 写小脚本按 10 个一组“只显示该组”或“只隐藏该组”，看白块变化
3. 找到后把 hide 列表写进该套的渲染命令

## 5. 工具与命令

### 5.1 渲染

```powershell
cd C:\Users\林\Documents\大掌柜

# 单套 / 多套
python tools\render_skin_spine.py --ids 109744 109754 --pma 0 --noblend --out "C:\...\out"

# 带 hide
python tools\render_skin_spine.py --ids 109720 --pma 0 --noblend --hide "0110" --out "..."

# 取动画末帧（慎用）
python tools\render_skin_spine.py --ids 109727 --pma 0 --noblend --anim idle --time end --out "..."
```

常用参数：
- `--pma 0`：直通 alpha（场景皮必须）
- `--noblend`：跳过叠加层
- `--hide`：逗号分隔，纯数字精确、其他子串
- `--anim idle --time end`：末帧
- `--width 1400 --height 1800 --scale 2`：默认，输出约 1000–1300 px 宽
