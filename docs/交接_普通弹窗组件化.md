## 4. 迁移配方（一次一页）

1. 找到页面里 `_create_base_popup` 的调用点与紧随其后的内容构建。
2. 按语义替换：
   - 一行「名称 + 数值」→ `c.popup_kv_row`
   - 一组内容块 → `c.popup_card`（返回的 VBox 里塞原内容）
   - 带小标题的分组 → `c.popup_section`
   - 长列表 → `c.popup_scroll`（返回 VBox，别再手写 ScrollContainer）
   - 底部按钮 → `c.popup_button_row`
3. 删掉自造的 `StyleBoxFlat` 暗底/紫边，改用色令牌。
4. **保留**所有回调、数据读取、禁用条件、红点逻辑；逐行对照原实现。
5. 审计：`git diff` 只含目标弹窗块；解析通过（见 §7）。

var panel = c._create_base_popup("菜谱升级", Vector2(360, 250))
var vbox = panel.get_child(0)

var name_lbl := Label.new()
name_lbl.horizontal_alignment = HORIZONTAL_ALIGNMENT_CENTER
name_lbl.add_theme_font_size_override("font_size", 16)
name_lbl.add_theme_color_override("font_color", UiHelpers.PAPER_TEXT)
vbox.add_child(name_lbl)

var card: VBoxContainer = c.popup_card(vbox, 84)

info.autowrap_mode = TextServer.AUTOWRAP_WORD_SMART
info.add_theme_color_override("font_color", UiHelpers.PAPER_TEXT_SUB)
