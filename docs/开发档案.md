## 一、开工顺序

1. `AGENTS.md` 自动加载（环境、红线、文件地图）。
2. 看本文件 §三「当前指针」——当前做到哪、下一步是什么。
3. 动手前按需查《开发规范》对应节；遇到"这功能怎么是空的"先查《踩坑》§静默失效。
4. 先跑一次 headless 基线（命令见 `AGENTS.md` §1），确认不是接手就带病。
