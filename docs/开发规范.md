# 《大掌柜》开发规范

> 本文件 = 规矩唯一权威（慢变）。状态/待办看 [开发档案](开发档案.md)，历史踩坑看 [踩坑](踩坑.md)。
> 事实基准：2026-10-19 对仓库实测。这里只写「换谁来做都该遵守」的规矩，不写批次流水。
> 维护：新坑先进《踩坑》，被 ≥2 批复用或用户拍板后，压缩进本文件对应节。

## 一、架构分层与访问纪律

```text
game_controller.gd   场景壳 / 页面与视图分发 / update_all_ui 汇流 / 布局总闸
game_data.gd         中枢：状态、系统实例、配置、转发器、SYSTEM_LIST
hero_data.gd         门客资质与「赚钱」唯一计算入口（纯静态，不可 new）
systems/*.gd         纯逻辑 RefCounted，持 var g（= GameData）
ui/pages/*.gd        纯 UI RefCounted，持 var c（controller）/ var data（GameData）
ui/base_view.gd      全屏视图基类
ui/ui_helpers.gd     弹窗工厂 / 结果弹窗 / 规则弹窗 / 公共控件（真正实现处）
```

- **pages 层没有 `g`**，只有 `c` 和 `data`；systems 层用 `g.xxx`。
- RefCounted 模块**没有任何 Node 方法**（`has_node` / `find_child` / `add_child` 全无），节点操作一律 `c.xxx`。
- `data.heroes` 只含已拥有门客；全量配置查 `data._hero_configs`。
- 视图命名：`show_<key>_view()` / `hide_<key>_view()`，`VIEW_LIST` 的 key 必须与方法中段一致（`show_view` 会校验并 `push_error`）。
- 主页面用 `visible` 切换，全屏视图走 `show_view` / `hide_view`；给页面挂钩子前先确认该页真实切换路径是什么。
- percent 一律小数制；配置里的百分数在消费端 `/100`。

## 二、清单驱动：新增系统/视图的唯一正确姿势

`SYSTEM_LIST` 一条 = `{key, script, cfg_var, cfg}`，实例化、存读档、启动校验全吃这张表。

- 新系统 = `var` 声明 + `SYSTEM_LIST` 一条；`cfg_var` 声明行加 `@warning_ignore("unused_private_class_variable")`。
- **清单顺序 = 读档认领顺序**（`drugshop_system` 必须排在 `talent_system` 前：天赋同步要读药铺勋章上限）。
- 不进清单的只有三类例外：`cuzhi` 构造内自加载、`item/travel/stage` 有副作用的专用 loader、`net_system` 生命周期独立。**全部要在 `CONFIG_SPECIAL_LOADERS` 登记**。
- 新 JSON 必须被 `SYSTEM_LIST.cfg` 或 `CONFIG_SPECIAL_LOADERS` 认领，否则启动 `push_warning`（当前 43 张全覆盖：30 条 cfg + 13 条特殊）。
- **别手写第二份 save/load 数组**：`_system_instances` 是唯一循环，双清单必漂移。
- 新视图 = `VIEW_LIST` 一条（key + var）；需要与主页互斥的再加进 `PAGE_CLOSE_LIST`（当前 18 项）。
- 新加成源 = `game_data` 里 `register_bonus` 一行（label / kind / fn），构成面板自动多一行，**不改 HeroData**。

## 三、弹窗协议

- 工厂**只创建不挂树**：调用方必须 `c.add_child(popup)`，弹窗一律挂 `c` 根节点。
- **工厂有两个入口，签名不同（历史高频踩点）**：
  - `c._create_base_popup(title, size, pos, with_close)` —— 4 参，`decorated` 写死 true（皮肤版）。
  - `ui_helpers._create_base_popup(title, size, pos, with_close, decorated)` —— 5 参；`decorated=false` 才是素面（规则说明用）。
  - 想素面却走 `c.` 前缀 = 参数被吞或直接报错。
- `_pos` 参数已废弃，一律居中，保留只为兼容旧调用。
- 关闭按名 `_safe_close` / 按节点；**禁**用捕获实例的 lambda 当关闭回调；**禁**同帧「删旧 + 重建同名弹窗」（`queue_free` 帧末才删，同帧重建被自动改名 → 按名找不回）→ 就地重建内容。
- 层级（实测 `z_index` 分布）：25 遮罩 / 30 弹窗 / 35 全屏页 / 36–38 抬层 / 39 页内遮罩 / 40 页内弹窗 / 45 确认 / 50 飘字 / 60 拖影 / 88 SyncMask / 90 登录门 / 95 对账顶窗。回调会触发 `update_all_ui` 的弹窗抬到 37/38。
- 弹窗分两类：**普通弹窗**走工厂羊皮纸皮肤（`decorated=true`，组件化只做这一套）；**画底弹窗**（酒肆 / 药铺 / 酒坊 / 妙音坊）用背景图 + 各自皮肤，内容定制，不套通用组件，只共用遮罩/居中/关闭/自适应外壳。
- 结果弹窗：`c._show_success_popup(文本, auto_hide, kind)`，`ok` 金 / `warn` 红 / `info` 浅；失败才红字，成功通常不弹（数值已可见）。
- 规则说明：`c._show_rule_popup(title, text)`，素面、点外部关、不自动关。
- 通用件优先复用，不重造：`_render_skill_tab`、`_cost_color`、`_add_cost_row`、`_add_btn_dot`、`flash_red`、`_show_quantity_selector`、`_format_gains`。

## 四、GDScript 红线

- **Tab 缩进**，不是空格；交付前查行首混入空格。
- GDScript 不支持关键字参数（`f(a = 1)` 式调用非法）。
- Godot 4 没有 `is_node_being_deleted`。
- `:=` 只用于可推断类型；`g.xxx`、字典下标、`min/max`、`.keys()`、`get_node`、跨对象方法调用一律显式标注。
- `and/or` 返回 bool；多行 lambda 不能直接链 `.bind()`（先赋 Callable 变量）；循环变量按引用捕获，需要按值就 `.bind(duplicate())`。
- tween/timer 回调首行 `is_instance_valid` 守卫；闭包只捕路径/int，不捕节点。
- 整数取大小 `mini/maxi`，整除 `floori()`；避免隐式整数除法告警。
- 变量/参数名避开 `seed/sign/wrap/floor/exp` 和 Node 基类属性（`name` 等）。
- Godot 4.7 下 `get_theme_font` / `get_theme_font_size` 不认默认参，必须显式双参 `("name", "Label")`。
- `Control.rotation` 绕 `pivot_offset`（默认左上角）：旋转成型节点先补 `pivot_offset = 半尺寸`。

## 五、布局与场景化

两种布局真相源，**不许混用**：

- 老页面（代码建 UI）：`_apply_portrait_layout()` 统一赋尺寸，禁锚点/offset 依赖。
- 场景化页面：布局只在 `.tscn`，脚本只灌内容，**禁二次钉布局**。

场景化四步：

1. `SCENE.instantiate()` 后**先 `free()` 旧壳再挂新壳**（用 `free` 不用 `queue_free`，同帧重建会断契约）。
2. 必需节点 fail-loud：`get_node` 直取，缺件立即报错，不写静默兜底。
3. 只灌动态内容（列表/数值/信号接线）。
4. 节点名 = 跨文件契约；挪节点位置要全仓同步 `get_node` 路径。

其它硬约束：

- 新建 Button 当帧 `size=(0,0)`，必须显式赋 size 或 `custom_minimum_size`；TextureRect 先 `expand=true` 再设尺寸。
- 不用锚点预设：`TOP_LEFT` + 显式 position/size。
- `ScrollContainer` 不把宽度分给孩子；**没有 `scrolled` 信号**（用 scrollbar 的 `value_changed` + 两帧恢复 + restored 闸门）；滚动轴上的孩子禁 `EXPAND`（会拉到视口宽 → 永远拖不动）。
- 手写 tscn：`[ext_resource]` 必须全部排在 `[sub_resource]` 之前；注释符是 `;` 不是 `#`；非根节点显式写全路径 `parent=`。
- 全局禁用「整行信息 + 右侧小按钮」（2026-09-26 用户拍板）：改卡片网格或「居中主卡 + 大号操作钮」。
- 面板页签/勾选状态用类变量记忆，不依赖节点重建默认值。

## 六、数据、配置与存档

- 项目 JSON 是 **Tab 缩进**风格；增量逐行插，**不要整体 `json.dumps` 重写**（会把缩进洗成空格）。
- 写完 JSON 必须全量解析校验（末键逗号坑已踩四次）。
- 概率用权重制；成长曲线**表驱动**配在 settings，禁止运行时硬凑拟合公式。
- 公式类配置必须代 **Lv1 / 20 / 100 / 600** 四档验算，别只验满级。
- JSON 数字进来全是 float：当字典 key、取模、循环次数前先 `int()`；Dictionary 的 int 键落盘会变 string（槽位键统一按字符串写，读取双查）。
- 存档：`save_id` 判血缘；原子写 `.tmp` → `.bak` → `rename`；`load_game` 保底链 `.bak` 自动恢复一次 → 仍失败 rename `.corrupt` 留证。
- 加成两种范式：**写入式**（差值补发进存档字段，默认）与**读取式**（新实体/上限判定/实时计数）。读取式必须乘在「源点」，跨玩法同口径走聚合 getter 单点求和。
- 读取式匹配静态属性时读配置（`g._xxx_configs`），不读存档快照（存档是解锁时刻的拷贝）。
- 加成注册表 `hero_data._bonus_registry`：`kind` = `apt` 资质 / `pct` 百分比（小数）/ `flat` 固定收入；`beast=true` 的条目在无兽试算时剔除。

## 七、工程手法与交付

- **改前先 grep 核实**：函数名、字段名、配置键、枚举值。编造符号是历史最高发事故，静态审计查不出「名字编造」。
- 旧文档里的行号、MD5、批次状态一律不可信；以现码 + `git log` 为准。
- 同文件多处修改**串行**做，改一处读一次；并行编辑会静默丢改。
- 多行替换/改缩进后跑栈式块解析器：`elif/else` 必须紧接同层 `if` 块尾，只核缩进会漏「位置错」。
- 引用任何类前先在 Godot 4.7 类参考确认存在（`HScrollContainer` 属 Godot 3，已删）。
- 不顺手优化范围外代码；不新增文件/重命名，除非本批必须。
- 注释只写**为什么**；机械批次标签只留关键行；删函数按「下一个同层 `func`」定边界，删后 grep 断言零残留。
- 交付 = 直接改工作区文件 + 给 `git diff` 摘要；**不主动 commit/push**，用户真机测过自己推；不打包 zip、不贴整文件。
- 交付前验证三件套：`--headless --path . --quit` 退出码 0 且无 `SCRIPT ERROR`；改动的 `.gd` 跑 `--check-only --script`；改动/新增 JSON 全量解析。
- 编辑器告警清零：`UNUSED` / `SHADOWED` / `INTEGER_DIVISION` 逐条修，不用下划线糊过去。
- 数据/口径修正要「三同步」：接口 + 显示 + 描述。只改代码不改显示 = 没接完。

## 八、玩法与经济口径

- 门客个体战力叫「**赚钱**」；全局挂机货币获取速度叫「**赚速**」，不得混用。
- 品质四档：`0=优秀 / 1=卓越 / 2=传奇 / 3=无双`（`heroes.json` 显式写）；品质色见 §九。
- 未接入的玩法在玩家 UI 统一写「后续版本开放」；机制说明不进玩家界面，进代码注释或本文件。
- 效果描述写**公式 + 叠加关系**，禁止写「已生效 / 已接入」。
- 成长曲线表驱动；十连语义统一为「升级 10 次（不足升剩余）」，勾选框互斥单选 + 类变量记忆。
- 货币池：门客独立池（百业经验/筹算值/厨艺值）与全局池（铜钱/元宝/交子/铜板/银条/信誉）分开；**专用耗材一律做普通道具进 items 轨**，不开独立货币 var。
- 四店体力/批次模型互不相同，别套用：医馆/药铺 = 体力池；酒肆 = 叫号（20 分钟/点，上限 50）；**客栈 = 灶位营业批次，无体力字段**（`cooking.count` 是本次营业剩余次数，只减不恢复）。
- 收益罐 + 队列批处理（`serve_queue` 进存档 + 定时器时间盒）是四店共通套路，资源字段各自不同。

## 九、素材与图标规则

图标命名（**查表优先，命名不对 = 静默回落不报错**）：

| 用途 | 路径 | 命名 |
|---|---|---|
| 技能图标（晋升/资质/委任/风姿/副业/促织） | `assets/skill_icons/` | `<技能名>.png`（中文） |
| 服装词条图标 | `assets/skill_icons/` | `<服装名>.png`（配置真名，不是 cos_id） |
| 服装立绘 | `assets/costumes/` | `<cos_id>.png` |
| 默认皮肤立绘 | `assets/portraits/{heroes,friends}/` | `<id>.png`（`*_cos` 目录为空，备用） |
| 信物 | `assets/heroes/` | `token_<去下划线 hero_id>.png` |
| 晋升字牌 | `assets/heroes/` | `plate_promo_<去下划线>.png` |
| 满级印章 | `assets/common/` | `manji.png` |
| 职业之道 | `assets/skill_icons/` | `career_shi[_ji].png` |

- 重名即共享（用户拍板）；缺图必须 `ResourceLoader.exists` 回落（品质圆底/首字），不得崩。
- 字形以配置为准，素材文件名与配置逐字一致（出过「献哈礼/献哈达」这类错字对不上）。
- 路径规则通用化前，先列存量目录的真实命名，再用 `ResourceLoader.exists` 对每张存量图跑真值。
- 运行时不识别运行中新增的图片文件，放图后需重启游戏（不是热重载）。
- 白底抠图必须做白色反合成去边 + 低透明硬切，否则铺满模式出现白圈。

品质色（全仓）：普通 `#f2f2f2` / 优秀 `#3498db` / 卓越 `#9b59b6` / 传奇 `#e67e22` / 无双 `#e74c3c`。

## 十、弹窗皮肤（羊皮纸）定式

工厂第 5 参 `decorated=true` 即皮肤版；素材全在 `assets/common/`：`popup_frame` 562×773 九切片 23/19/68/45、`popup_plaque` 220×40、四角整块原画。

内容边距 40/60/36/40 下的常量（坐标系 = 内容矩形）：

| 项 | 内容 |
|---|---|
| 金匾 plaque | CENTER_TOP `(-100,-50)` 220×40 |
| 左上飞檐 corner_l | TOP_LEFT `(-69,-58)` 103×83 |
| 关闭钮（灯笼 hit 区） | TOP_RIGHT `(10,-4)` 45×81 |
| 右上灯笼块（关闭钮子节点） | `(-11,-68)` 88×211 |
| 左下/右下底座角 | BOTTOM_LEFT `(-62,-48)` / BOTTOM_RIGHT `(-26,-48)` 112×88 |

硬规矩：

1. `PanelContainer` 是容器：直接子控件会被 fitted 到内容矩形强制重排 → 装饰贴片必须挂普通 Control 壳，禁直接挂面板。
2. 锚点常量由内容矩形推导；改 `content_margin` 后，锚在对应边的常量必须 ± 差值重推，注释写全公式，禁止裸数字。
3. `add_theme_color_override` 不传给子节点：面板级默认字色/样式要用 `Theme` 类型项挂面板，overlay 只对本控件生效。
4. 内容盖装饰 = `vbox.z_index = 1`；点击区必须留在内容矩形外（右边距 60 是灯笼自留地）。
5. 禁横滚双保险：工厂 ready 遍历子树禁横滚 + 运行期重建的滚动区在构建处自禁；根因还是构建时行宽之和 ≤ 弹窗宽 −100。
6. 页签弹窗按最大页内容定尺寸，多页容器全部 `SIZE_EXPAND_FILL` 填满同一矩形；「切换页签看起来大小变」多半是内容块居中上下跳。
7. 皮肤素材：九切片框体四边必须全实体；突出装饰（灯笼/飞檐/底座脚）不抠图，整块原画矩形钉壳。
8. 可点装饰挂按钮子节点，调用方按名摘除时装饰随之销毁，杜绝「看得见点不到」。

## 十一、已知的静默失效模式（优先怀疑清单）

| 症状 | 根因 | 排查 |
|---|---|---|
| 配置读出来恒空/恒 0 | 字段名写错（如 `career` vs `category`） | 先对 JSON 实档核字段名，再查代码 |
| 改了规则一处、另一处没变 | 同一业务规则多处实现 | 改前全仓搜全部实现点 |
| 加成代码齐全但数值恒零 | 写入式作用域配置为空 → 隐形未接入 | 查目标配置是否真有该技能/条目 |
| 同名 getter 数值对不上 | 跨系统同名异义（`get_refine_cap_bonus` 四系统四种含义） | 按系统实例确认作用域 |
| 玩法突然全 0 | 空容器采纳（空 Dictionary 也是 Dictionary） | 采纳后必须判 `is_empty` 自愈 |
| 整文件崩 / 解析错 | 替换块插错位置（`elif` 成孤儿） | 跑栈式块解析器验位置，不只验缩进 |
| 公式静默失效 | 行内注释吞掉了行尾表达式 | 拆多行，公式单独成行 |
| 图标「没出来」但无报错 | 路径/命名拼接失配，静默回落 | 文件在位（含 import）→ 代码版本 → 字符串逐字符 |
| 功能「已接入」但玩家看不到 | 只改接口没改显示/描述 | 三同步检查 |
