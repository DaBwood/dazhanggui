> 规则：任何「诶这里加个 XX 会更好」的念头，先写这里，**不进当前里程碑**。
> 只有和当前里程碑验收直接相关的，才允许捞出来做；其余的，等当前阶段验收通过再说。
> 每条格式固定，方便每周复盘时快速判断「还值不值得做」。

```

  - 服务哪个里程碑：M?

  - 预估：半天 / 1 天 / 3 天+
```

## 已否决（留档，避免反复想）

- 限时活动轮换（逐鹿隋唐/狩猎/夺魁）：live-ops 内容，单机复刻不追；最多做 1 个常驻。
- 真人排行榜 / 实时 PvP / 公会战：需要服务端与匹配，收益不匹配成本。
- 配音 / 多语言 / 内购 SDK：与「自娱自乐」定位冲突。
