# 想法池

> 规则：任何「诶这里加个 XX 会更好」的念头，先写这里，**不进当前里程碑**。
> 只有和当前里程碑验收直接相关的，才允许捞出来做；其余的，等当前阶段验收通过再说。
> 每条格式固定，方便每周复盘时快速判断「还值不值得做」。

## 模板

```
- [ ] 想法：一句话
  - 为什么想要：
  - 服务哪个里程碑：M?
  - 最早可做：M?
  - 预估：半天 / 1 天 / 3 天+
```

## 已否决（留档，避免反复想）

- 二周目 / 通关 / 结局：本项目没有通关概念（2026-10-27 拍板）；目标是追平原作版本并跟随更新。
- 真人实时 PvP / 实时公会战：需要实时同步与匹配，朋友局体量收益不匹配。
- 配音 / 多语言 / 内购 SDK：与「自娱自乐」定位冲突。
