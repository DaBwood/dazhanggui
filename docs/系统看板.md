# 系统看板

> 一句话：**40 个系统，逐行判「能不能玩」，每轮只允许动一行。**
> 判定依据：2026-10-22 读码实测（系统头注释 + 关键函数 + UI 页按钮接线），未做真机逐项验收。
> 2026-10-27 口径更新：本项目不做通关 / 二周目；商铺解锁表保留原作长线。真人排行榜改为 P2 弱联网（快照式）。
> 档位口径：
> - **可玩**：进入 / 操作 / 产出 / 存档四件事在代码层闭合（不等于手感好）。
> - **半成品**：主循环能跑，但有明确未接的分支（按钮弹「后续版本开放」或效果灰显）。
> - **骨架**：只有数据结构与最小操作，没有完整玩法。
> - **占位**：只有配置或字段。
> 「真机」列从 M1 开始逐项打勾；没打过勾的，一律不算完成。

## 统计

| 档位 | 数量 | 占比 |
|---|---|---|
| 可玩 | 35 | 87.5% |
| 半成品 | 5 | 12.5% |
| 骨架 | 0 | 0% |
| 占位 | 0 | 0% |

**结论：机制层比想象中厚。** 40 个系统里 35 个主循环已闭合，真正断的是 5 个「资源已经花出去、效果没落地」的半成品，以及主线串联和表现层。所以路线图先做 M1/M2 的串联与校准，不是补系统。

## 最该先补的 5 个缺口（按对核心循环的影响排序）

1. **副业两个币种无产出**（`side_skill_system.gd:23-24`）：百工百业、物宝天华 2/6 条资质线永久卡死，只扣不加，属硬断头。
2. **天赋七类效果未实装**（`talent_system.gd:457-459`）：天赋档位给玩家看却无数值，直接削弱门客成长与抽卡价值。
3. **藏品 38 个特殊效果未接线**（`collection_view.gd:462`）：合成/升星后无实际增益，藏品核心追求落空。
4. **挚友无双技能空页**（`friend_page.gd:636`）：无双挚友养成断在最后一页，而挚友是门客主力加成源。
5. **神话门客入口只弹提示**（`hero_page.gd:76`）：顶级追求缺失，影响后期目标感，不影响前中期。

前四项都是负反馈（花了资源没效果），优先修；第五项是内容增量。

> 主线级问题不在这张表里：商铺解锁表、关卡曲线、新手引导、VIP 收口——见 [路线图](路线图.md) §2.4 与 §5。

## 维护规则

- 每完成一个任务，只改对应行：档位 / 缺口 / 真机打勾。
- 真机打勾必须写日期，例如 `☑ 10-24`；没写日期的勾不算。
- 新增系统先加行，再写代码；不允许「代码有了、看板没有」。
- 档位只升不降；如果发现回退，在缺口列写清原因，不要偷偷改回「可玩」。
