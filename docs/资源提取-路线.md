## 3. 纹理格式（已解）

### 3.1 文件结构

```
6c 79 71 73 7a 70   "lyqszp"（6 字节魔数）
+ XOR 0x70 后的内容
```

- `.png`：XOR 后直接是标准 PNG（`89 50 4E 47 ...`），带 alpha。
- `.pkm`：XOR 后是 **gzip**（`1f 8b`），解压后是 `PKM ` ETC1。

PKM 头 16 字节：

```
"PKM " + "10" + type(u16 BE) + width(u16 BE) + height(u16 BE)
      + origWidth(u16 BE) + origHeight(u16 BE)
```

实测 7,973 个 PKM **全是 type 0（ETC1）**；宽高是 4 对齐后的，orig 是实际尺寸。ETC1 没有 alpha，所以部分图集把**遮罩/alpha 画在另一半区域**（例如 2048×4096 图，上半是颜色、下半是黑白遮罩）。

### 3.2 工具

- `tools/extract_textures.py`：批量解密 PNG / 解压 PKM / 调 `etc1.py` 转 PNG。
- `tools/etc1.py`：纯 numpy ETC1 解码器（无第三方依赖，MIT/Unlicense 参考 `etcdec`）。
- 单张转换：
  ```powershell
  python tools\etc1.py in.pkm out.png
  ```

### 3.3 已知限制

- ETC1 无 alpha：需要透明的 UI 图优先用 `textures/png/`（2,175 张，带 alpha）。
- `.pkm` 解码出的是**整张图集**，不是单张 sprite；拆图要配 FairyGUI 包或 `.plist`。
- 少数 PKM 可能是 ETC2（T/H/planar），当前解码器按 ETC1 处理；遇到花屏再补。
