## 3. 纹理：`lyqszp` 是什么

`.png` 和 `.pkm` 的文件头都是：

```
6c 79 71 73 7a 70   =  "lyqszp"
```

后面不是 PNG（`89 50 4E 47`）也不是 PKM（`50 4B 4D 20`）。`libcocos2djs.so` 里能找到 `lyqsz` 字符串，紧挨着 `DDS / WEBP / pngReaderCallback`，说明这是引擎注册的**自定义图像格式/解码器**，不是标准 Cocos XXTEA 资源。

三条路，按成本排序：

1. **先试 cc-reverse**（[GitHub](https://github.com/Crain99/cc-reverse)）。它支持 2.4.x，能自动提 XXTEA 密钥、拆 `project.js`、导出 PNG/PLIST/音频/Spine。若它不认 `lyqszp`，会原样保留，不会更糟。
   ```powershell
   cc-reverse --path <APK 解压目录> --version-hint 2.4.x --verbose
   ```
2. **Frida 动态 dump（最可靠）**。在真机/ARM 模拟器上跑游戏，hook 图像解码入口，把解码后的 RGBA/PNG 落盘：
   - hook `cocos2d::Image::initWithImageData` 或 `lyqsz` 解码函数；
   - 或 hook `jsb_set_xxtea_key` / `xxtea_decrypt` 拿到密钥后离线解。
   这是处理自定义格式的通用解法，代价是要一台能调试的 Android 设备。
3. **静态逆向 `libcocos2djs.so`**（Ghidra/IDA）。围绕 `lyqsz` 字符串找解码函数，还原算法。最慢，但一次搞定后可以批量离线解。

> 建议顺序：先跑 1，半天内出结果；不行就上 2，别再猜算法。

python tools\extract_jwdzg.py --apk C:\Users\林\Downloads\jwdzg.apk --out _apk_extract --what text

### 4.3 音频 / Spine 描述 / FairyGUI

```powershell
python tools\extract_jwdzg.py --apk C:\Users\林\Downloads\jwdzg.apk --out _apk_extract --what media
```

> `--what media` 只拷 `.mp3/.ogg/.wav/.atlas/.bin/.ttf`；加密纹理记 `skip-texture`，不算失败。调试可加 `--limit 50` 只跑前 50 项。

### 4.4 FairyGUI 还原

- 工具：[fgui-restore](https://github.com/krapnikkk/fgui-restore)（FairyGUI 资源逆向还原）。
- 输入 `*.bin` + `*_atlas0.png`；输出可编辑的 FairyGUI 工程。
- 纹理加密时，先解纹理，再还原包；否则只能看组件树/坐标，看不到图。

### 4.5 纹理

按 §3 的三条路走。产出统一放 `_apk_extract/textures/`，按原路径命名，方便和 `config.json` 对齐。

## 5. 这套东西能用来干什么

1. **对数值**：`GameConfigDB` + `GameShopDB` + `GameStageDB` + `HeroRankDB`，直接看原作的曲线/价格/关卡难度。这是“原作为什么顺”的第一手证据。
2. **对系统**：`SystemInfoDB` / `SystemGuideDB` 能看出原作的**系统开放顺序**和引导节奏——比猜靠谱。
3. **对 UI**：FairyGUI 包给出组件树、坐标、九宫格、字体；比截图量尺寸准。
4. **对素材**：音频/Spine/立绘（纹理解出来后）可直接替换现有占位。
