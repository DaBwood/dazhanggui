# 《大掌柜》踩坑速查

> 只收「换个人来做也会踩」的坑，一条一个症状 + 根因 + 对策。规矩的正式表述在 [开发规范](开发规范.md)。
> 平台/沙盒类事故（ipython 内核重置、upload 只读、zip 回读、对话接力丢文件）已剔除——那些属于旧工具链，不随项目走。
> 旧 Kimi 档案（Downloads `preview-*.md`）里保留完整溯源，需要查原始场景再去翻。

## 一、GDScript 语言

1. **解析错：Unindent / 缩进不匹配** —— 字符串替换时手滑多一个 Tab，或文件里混入空格缩进。→ 改完跑「相邻有效行缩进差 ≤ +1 Tab」审计，别靠肉眼。
2. **`Cannot infer the type of "x"`** —— 给 `:=` 喂了无类型来源（`g.xxx`、字典下标、`min/max`、`.keys()`、跨对象方法调用）。→ 一律显式 `var x: int = ...`。
3. **数值算出来少一截 / 取模结果怪** —— JSON 里的数字都是 float。→ 当 key、取模、循环次数前 `int()`；`%` 前先转 int。
4. **存档里的槽位键读不到** —— Dictionary 的 int 键落盘变 string。→ 槽位键统一按字符串写，读取时 int/string 双查。
5. **`or` 当默认值合并失效** —— GDScript 的 `and/or` 返回 bool，不是返回操作数。→ 用三元或显式判空。
6. **循环注册的回调全指向最后一个元素** —— lambda 按引用捕获循环变量。→ `.bind(值)` 或 `bind(duplicate())`。
7. **多行 lambda 后直接 `.bind()` 解析错** —— 语法不允许。→ 先赋给 Callable 变量，再 `.bind()`。
8. **页面关了，定时器回调还去改节点 → 崩** —— 引用悬挂。→ 回调首行 `is_instance_valid`；闭包只捕路径/int，不捕节点。
9. **整数除法静默丢小数** —— `/` 两边都是 int。→ 用 `floori()` 或 `/10.0`。
10. **标识符冲突 / 覆盖引擎函数** —— 变量名撞 `seed/sign/wrap/floor/exp`，参数名撞 Node 的 `name`。→ 改名，别用下划线糊告警。

## 二、节点与容器

11. **新建 Button 尺寸是 0，点不到也看不见** —— 当帧还没排版。→ 显式赋 `size` 或 `custom_minimum_size`。
12. **TextureRect 设了 size 不生效** —— 没开 `expand`。→ 先 `expand = true` 再设尺寸。
13. **滚动条拖不动 / 内容永远不满** —— 滚动轴上的孩子挂了 `EXPAND`，被拉到视口宽。→ 滚动轴孩子禁用 EXPAND。
14. **想监听 `ScrollContainer.scrolled` 报错** —— 该信号不存在（只有 scroll_started/scroll_ended）。→ 用 `get_v_scroll_bar().value_changed` + 两帧恢复。
15. **透明层挡住所有点击** —— 透明 `Control` 默认 `MOUSE_FILTER_STOP`。→ 常驻透明装饰显式 `IGNORE`。
16. **挪了节点，功能静默消失** —— `get_node` 路径没跟着改，节点"游离但存在"。→ 挪容器前先 grep 该节点全部引用点，改完逐点复读。
17. **从子视图返回后主页空白** —— 批量显隐循环把场景实例整层隐藏；父不可见时子节点 `visible=true` 也不渲染。→ 恢复时要恢复实例层，不只是子层。
18. **PanelContainer 里的装饰被拉到正中** —— 容器的直接子控件会被 fitted 到内容矩形。→ 装饰挂普通 Control 壳。
19. **旋转的菱形/斜签对不齐** —— `Control.rotation` 绕 `pivot_offset`（默认左上角）。→ 先补 `pivot_offset = 半尺寸`。
20. **手写 tscn 加载报 `Unknown tag 'ext_resource'`** —— `[ext_resource]` 排在了 `[sub_resource]` 后面。→ 全部 ext 放最前。
21. **tscn 里写 `#` 注释直接 Parse Error** —— tscn 注释符是 `;`。→ 全文搜 `#`。

## 三、弹窗

22. **弹窗创建了但看不见** —— 工厂只创建不挂树。→ 调用方必须 `c.add_child(popup)`。
23. **弹窗内部取节点越界 / 取到标题** —— 按位置取件，`vbox` 首子永远是 `PopupTitle`。→ 按名字 `get_node("Xxx/Name")`。
24. **关了弹窗再建同名弹窗，按名找不回** —— `queue_free` 帧末才删，同帧重建被自动改名。→ 原地重建内容，别删旧建新。
25. **遮罩残留全屏压暗，哪都点不了** —— 同名弹窗/遮罩的旧实例没死。→ 关闭走 `_safe_close`，弹窗挂 `c` 根。
26. **弹窗被全屏页盖住** —— z 序低于 35 的全屏页。→ 页内弹窗：遮罩 39 + 弹窗 40；回调触发全局刷新时抬到 37/38。
27. **想用素面弹窗却出皮肤** —— 走了 `c._create_base_popup`（4 参，`decorated` 写死 true）。→ 直接调 `ui_helpers._create_base_popup(..., false, false)`。
28. **弹窗里字色不跟着主题走** —— `add_theme_color_override` 只对本控件生效。→ 面板级默认色用 `Theme` 项挂面板。

## 四、数据与配置

29. **JSON 解析失败，末键多了逗号** —— JSON 不允许尾逗号（已踩四次）。→ 写完必跑全量 `json.loads` / `ConvertFrom-Json`。
30. **配置差异审计变成几千行** —— 整体 `json.dumps` 重写把 Tab 缩进洗成空格。→ 逐行增量插，审计要求「0 删除行」。
31. **配置字段读出来恒空** —— 字段名凭记忆写错（真实案例：`category` 写成 `career`，整条加成链恒 0）。→ 引用前对 JSON 实档核字段名。
32. **概率/权重改了没生效** —— 读的是存档快照而不是配置，或读的是另一份同义配置。→ 静态属性一律读 `g._xxx_configs`。
33. **空字典被当成"有数据"** —— `is Dictionary` 通过后直接采纳，聚合产出归零（酒肆设施表死锁案）。→ 采纳后必须判 `is_empty` 自愈。
34. **公式在低等级崩成个位数** —— 只按满级拟合曲线。→ 代 Lv1/20/100/600 四档验算。
35. **同一规则改了一处，另一处没变** —— 规则多处实现。→ 改前全仓搜全部实现点（含点击处理、兜底分支）。

## 五、存档

36. **强杀编辑器后存档截断，读档静默重开新档 → 旧档被覆盖** —— 直写式 save。→ 原子写 `.tmp` → `.bak` → `rename`，`load` 失败先 `.bak` 恢复，再失败 rename `.corrupt` 留证。
37. **云端和本地互相覆盖** —— 没判存档血缘。→ `save_id` 同血缘才比时间，复制存档必须重发 `save_id`。
38. **"只读不写"的存档字段永远为 0** —— 读档清零型字段漏写回。→ 存读档键位对自检（`_selfcheck_save_key_pairs`，仅编辑器期跑）。

## 六、交付与验证

39. **静态审计全绿，一跑就崩** —— 审计查不出"函数名编造"。→ 交付前必须真跑 `--headless --path . --quit`，改动的脚本再跑 `--check-only`。
40. **功能"已接入"但玩家看不到** —— 只改了接口，没改显示和描述。→ 三同步：接口 + 显示 + 描述。
41. **图标"没出来"但没有任何报错** —— 路径/命名拼接失配，代码静默回落。→ 排查三序：文件在位（含 import）→ 代码版本 → 字符串逐字符比对。
42. **审计脚本自己误报** —— 断言用了自然语言词，而该词出现在注释里。→ 用旧代码特征串（函数名/变量名）做断言。
43. **差异审计混入无关改动** —— 基线不是最新 main。→ 开工先 `git fetch` + 核对 HEAD，`git diff` 只看目标文件。

## 七、协作与流程

44. **同一文件多处修改，有的没生效** —— 并行编辑/多刀同发导致静默丢改。→ 串行，一条改完读盘再下一条。
45. **接手后按文档找不到文件** —— 文档里的文件名/行号过期（真实案例：`beast_view.gd` 实为 `beast_page.gd`）。→ 文档事实必须当场核；行号一律不写。
46. **把旧档案的"状态"当现状** —— 交接文档会滞后于代码（酒肆迁移就没入档）。→ 状态以 `git log` + 现码为准，文档只作线索。
47. **测试用例"通过"了但功能是坏的** —— 断言写错（复合断言查错文件、只断言单接口 200）。→ 验证脚本先小样本自测；认证/会话类必须测全链路。
